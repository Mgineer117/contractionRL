# Analytical-car Bayesian search

The 2026-10-20 relaunch uses `search/configs/car-c2rl-bayes-encoder-pairs.yaml`: 192 Bayesian trials, seed 42, 500,000 steps and 128 parallel analytical Car plants per trial. It searches discount `[0.9, 0.99, 0.999]`, GAE lambda `[0.9, 0.95, 0.99, 1.0]`, action-bound penalty `[0.01, 1.0]`, value expansion and value normalization booleans, CCM bounds `0.1:1.0`, `0.1:3.0`, `0.3:3.0`, and the coupled policy/critic encoder choices `(null, null)`, `(null, gru)`, `(gru, gru)`. All other settings remain fixed in the resolved environment config. CMGs use physical x only; each trial trains a fresh metric. The named Isaac-Classic task executes through its identical `classic-car-v0` analytical alias, without starting a renderer. The same saved validation and holdout banks are retained.

`encoder_pair` is expanded into both model roles before training. The nested trainer consumes that resolved config once; the outer W&B run owns search metadata and scalar logging. GRU widths and windows follow `models.encoder`, with null defaults of `3 * x_dim` and `ceil(1 / (1 - discount_factor))`. GPU workers must pass compact, privileged-critic and shared-GRU preflights with finite policy movement before starting official Bayesian agents.

Superseded campaign configs and results remain in Git history and frozen experiment snapshots.

Every trial learns a fresh CCM with its sampled structural spectral bounds using the analytical dynamics, then freezes it for PPO. Analytical tasks fit no dynamics model. MVE uses the exact nominal analytical equations and the frozen metric; physical training rollouts retain their hidden bounded gusts. Training metrics keep their existing W&B names, and metric pretraining uses negative environment-step coordinates.

The Bayesian objective is `Evaluation/Stability/validation_auc_mean`, computed once at the final checkpoint on 512 persisted reference/initial-state/gust/action-noise cases. It is separate from online training AUC. All failed cases are retained. Failed or incomplete trials are recorded as failures and do not receive a valid objective. A separate 512-case holdout bank is excluded from Bayesian suggestions. One training seed and mixed GPU/runtime versions limit claims about reproducibility and generalization.

Analytical MVE now uses the exact nominal drift/actuation plus an independent `BoundedGust` for every imagined branch. Gusts persist across that branch's horizon using the same magnitude and hold-time generator as the plant. Each imagination batch starts with a fresh private gust draw, so it samples a prior over the hidden disturbance rather than inferring its conditional posterior from measured history. It never reads or changes the plant's gust value or remaining dwell. References remain nominal, and preparation's RNG scope prevents imaginary sampling from advancing real-rollout exploration. Sim-to-real continues to sample the learned conditional disturbance density in model rollouts.
