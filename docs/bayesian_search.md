# Analytical-car Bayesian search

The search configuration is `search/configs/car-c2rl-bayes.yaml`; `search/train_bayes.py` resolves each W&B proposal and runs the existing training entrypoint in an isolated agent child process. The user-authorized cap is 96 trials, each with 500,000 vector steps, 128 environments and training seed 42. W&B's shared `run_cap` bounds the whole sweep across machines; each agent also has a finite count. Existing experiments are preserved.

The eleven choices are compact MLP versus future/history GRUs; paired W lower/upper bounds; value normalization; neural-feature normalization; MVE with horizon 10; gradient clipping; GAE lambda; rollout length; PPO epochs; minibatches; and structured residual versus factorized control. Both actor and critic use 256-by-256 MLPs. The temporal branch has separate future/history GRUs for each network, with 64 internal units and 4-dimensional output embeddings. The compact branch receives the existing relative-position tracking features derived from `(x, xref, xi)`, including boundary distances.

The structured mean is `uref + W2(s) tanh(W1(s) error)`. The factorized alternative is `W2(s) tanh(W1(s))`, with neither feedforward addition nor error multiplication. Both use learned additive Gaussian exploration and physically clipped applied controls. Discount 0.9, learning-rate/KL-adaptation settings, action-overflow penalty beta 1, disturbances, reference generation, reward and termination are fixed.

`use_state_norm` normalizes neural context features only, after the relative-coordinate transformation and any GRU encoders. It never normalizes the physical state used by dynamics, metric evaluation, tracking error or reference feedforward. Running statistics update once from real rollout observations after the entire PPO and optional MVE update, and remain frozen during rollout collection, likelihood replay, gradient steps, imagined rollouts and playback. A variance floor handles constant features, and neural normalized features are clipped to +/-10. Statistics are saved in actor/critic checkpoints.

Every trial learns a fresh CCM with its sampled structural spectral bounds using the analytical dynamics, then freezes it for PPO. Analytical mode fits no dynamics model. MVE uses the exact nominal analytical equations and the frozen metric; physical training rollouts retain their hidden bounded gusts. Training metrics keep their existing W&B names, and metric pretraining uses negative environment-step coordinates.

The Bayesian objective is `Evaluation/Stability/validation_auc_mean`, computed once at the final checkpoint on 512 persisted reference/initial-state/gust/action-noise cases. It is separate from online training AUC. All failed cases are retained. An incomplete or failed trial receives objective 1,000,000; valid objectives are capped below that value. This affects search ranking only, not the MDP or training reward. A separate 512-case holdout bank is excluded from Bayesian suggestions. One training seed and mixed GPU/runtime versions limit claims about reproducibility and generalization.

The disturbed-MVE rerun uses `search/configs/car-c2rl-bayes-disturbed-mve.yaml`. It fixes running feature normalization off and value normalization on, narrows CCM pairs and PPO batch/update choices. Initial learning rate is fixed at 1e-4 with KLAdaptiveLR (threshold 0.008, KL factor 2, LR factor 1.5, limits 1e-5 to 1e-3), as requested; it is not a search dimension. The reward, control limits, hidden physical gusts, references and termination rules stay fixed. The objective and validation/holdout banks are identical to the first campaign.

Analytical MVE now uses the exact nominal drift/actuation plus an independent `BoundedGust` for every imagined branch. Gusts persist across that branch's horizon using the same magnitude and hold-time generator as the plant. Each imagination batch starts with a fresh private gust draw, so it samples a prior over the hidden disturbance rather than inferring its conditional posterior from measured history. It never reads or changes the plant's gust value or remaining dwell. References remain nominal, and preparation's RNG scope prevents imaginary sampling from advancing real-rollout exploration. Sim-to-real continues to sample the learned conditional disturbance density in model rollouts.
